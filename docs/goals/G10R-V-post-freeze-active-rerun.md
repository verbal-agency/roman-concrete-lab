# G10R-V — Run the post-freeze active-investigation comparison

**Status:** complete — `DO_NOT_ESCALATE_ACTIVE_SOCIETY`
**Dependencies:** G10R-X fresh post-wiring freeze; explicit owner
activation naming the new manifest ID/hash, provider,
network permission, and the `$25` aggregate cap
**Authority:** no model, network, credential, subscription, or paid action is
permitted until the owner activates this goal in writing; after activation,
only the exact frozen manifest and read-only host policy may be used

## Objective

Run one separately namespaced A1 single-investigator versus A2-M society
comparison using the post-wiring manifest and repaired research-loop runtime. Measure
whether the society produces a unique source-backed contribution, useful
hypothesis, or discriminator under equal aggregate budgets. This is a
directional engineering evaluation, not evidence promotion, scientific
validation, laboratory authorization, or production adoption.

## Activation gate

Execution must stop before provider initialization unless the owner explicitly
confirms all of the following: the exact post-wiring manifest ID and hash, OpenAI
Responses provider/model, read-only network permission, the frozen source-host
policy, the `$25.00` hard aggregate cap, and the output namespace
`artifacts/goals/G10R-V/`. A cycle invocation alone does not satisfy this gate.

## In scope

- the four frozen sealed cases and A1/A2-M treatments from the manifest;
- search → candidate selection → fetch/map, dossier revision, focus, open-slot,
  replay, and typed scoring contracts from G10R-T;
- checkpointed provider traces, request lifecycle, source/evidence ledgers,
  dossier revisions, component scores, and cumulative spend;
- blinded case scoring and a post-run report separating discovery, evidence,
  hypotheses, weakening, unresolved identity, blocked access, and overhead;
- a deterministic offline replay of the completed run.

## Explicit exclusions

No source-policy or budget expansion, new hosts, subscriptions, Sci-Hub access,
laboratory work, evidence promotion, automatic retry after a terminal outcome,
or follow-on paid run. Simulation remains `SIMULATOR_UNAVAILABLE`; synthetic or
unvalidated output cannot earn empirical evidence credit.

- `artifacts/goals/G10R-V/manifest.json` copied by hash from the G10R-X

- `artifacts/goals/G10R-V/run.json` and per-case checkpoints;

## Goal-level acceptance criteria

1. The run refuses to initialize without the explicit activation record and
   exact manifest ID/hash; stale or altered manifest inputs fail closed.
2. Both arms use equal frozen ceilings and the same configured source policy;
   actual usage, provider calls, fetches, tokens, and spend are recorded per
   case and in aggregate.
3. Every discovered candidate, fetch/map action, paper card, report, dossier
   revision, critique, focus action, and open-slot decision has stable lineage
   and replay-safe checkpoint membership.
4. The scorer separates discovery, evidence, task accuracy, useful hypothesis,
   discriminator, authority, provenance, efficiency, and cost; wording alone
   cannot change the result.
5. The report emits exactly one of
   `ESCALATE_ACTIVE_SOCIETY_EVALUATION`,
   `DO_NOT_ESCALATE_ACTIVE_SOCIETY`, or
   `INCONCLUSIVE_ACTIVE_INVESTIGATION`, and no outcome authorizes laboratory
   work or evidence promotion.
6. Focused tests, the full suite, and offline replay pass before the report is
   finalized; historical G10R-U and earlier artifacts remain unchanged.

## Handoff

If the outcome is positive, it may propose a later adoption review or lab gate;
it does not grant scientific authority. This run returned
`DO_NOT_ESCALATE_ACTIVE_SOCIETY`; the result is routed to G10R-Y for offline
post-run diagnosis rather than repeated paid execution.
