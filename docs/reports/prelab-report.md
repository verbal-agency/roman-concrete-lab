# Non-agent exploratory platform pre-lab release

**Release mode:** `EXPLORATORY_PLATFORM`
**Source branch:** GP4 → G07E
**Build command:** `PYTHONPATH=src python3 -m roman_concrete_lab.release.build --version 2026-09-30-exploratory-platform --output artifacts/releases/2026-09-30-exploratory-platform`

This report is the human-readable release entry point. The redistributable bundle is generated from the frozen GP4 cards, G07E tournament fixtures, evidence manifests, rights log, schemas, and policy hashes. It contains metadata and derived claims only; restricted full text and credentials are excluded.

The release is intentionally non-agent and non-lab. Its normal outputs are conditional Pareto sets and draft experiment questions. It does not establish physical performance, infer a recipe, authorize safety approval, or identify a universal best material.

Inspect `artifacts/releases/2026-09-30-exploratory-platform/manifest.json` for artifact hashes, `claims.json` for evidence-linked public claims, `rights.json` for access obligations, and `reproduction.json` for the clean-build commands.
