# Roman Concrete Lab

This repository has completed **G00 for the exploratory plane**. It is not a lab protocol or a predictive discovery system.

The G-1 audit found an exploration-seedable but not model-ready evidence base. The permitted near-term product is a provenance-preserving, problem-specific evidence-to-question substrate for modern terrestrial Roman-inspired hot-mixed lime-pozzolan mortar. It may produce provisional candidates, rival hypotheses, and experiment questions. It may not claim effectiveness, infer a recipe, train a generalizable model, execute a lab study, or introduce an agent society.

The approved charter and deferred gates are in [`docs/decisions/0001-program-charter.md`](docs/decisions/0001-program-charter.md). The execution order and stop rules are in [`docs/roadmap.md`](docs/roadmap.md). The repository remains unlicensed pending the later release decision recorded in [`LICENSE-PENDING.md`](LICENSE-PENDING.md).

G00 authorizes GP1–GP4 with no external spend, lab work, model training, or agent runtime. Scientist review, commercial licensing, extraction thresholds, and agent-provider choices remain later gates.
